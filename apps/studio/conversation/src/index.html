CHATGPT E COMPUTADOR
ORDAX Studio

    
Conecte o plugin à mesma conta ChatGPT usada no app. O ChatGPT poderá consultar a tela, trabalhar com projetos e usar as ferramentas autorizadas no seu dispositivo OrdaX.

    

    
  1. Abra o cadastro no ChatGPT na área da conversa. Em Plugins → Adicionar → Criar servidor MCP personalizado, volte ao Studio e use Preparar cadastro novamente para preencher nome, descrição e URL. Se o formulário mudou, copie os campos abaixo.
  2. Escolha URL do servidor e autenticação OAuth. Abra as configurações avançadas e siga o guia OAuth.
  3. Leia o aviso do ChatGPT, marque Entendo e quero continuar se concordar e use Criar como plugin. Instale o plugin e conclua o login OrdaX quando solicitado.
  4. Use Voltar à conversa Web e selecione @ORDAX Studio no compositor. Vincule o dispositivo e autorize as capacidades no OrdaX Studio.

    

    

    
Ícone opcional: pode deixar vazio. Se usar um, a tela aceita PNG, até 10 KB, preferencialmente 256 × 256 pixels ou mais.

    

    
Guia das configurações avançadas de OAuth
Clique em Verificar serviço para obter as configurações OAuth publicadas. Use registro dinâmico de cliente (DCR) quando confirmado; nesse modo, não preencha ID nem segredo de cliente manualmente.
Mantenha a descoberta automática dos endereços. Se a tela solicitar preenchimento manual, copie os valores verificados abaixo. Se ela só oferecer cliente estático, será necessário um cliente OAuth cadastrado pelo administrador OrdaX.

      

      

      

      

      

      
Use PKCE S256. ID e segredo de cliente são gerados no registro dinâmico; não cole senha, token do Runtime ou chave de API nesses campos. Os escopos de login não concedem acesso ao computador: as permissões são definidas no Studio.

    
A área do ChatGPT usa sua sessão interna. Sua conversa local e seus rascunhos permanecem salvos; volte à conversa Web ao terminar. O navegador externo mantém uma sessão separada.
