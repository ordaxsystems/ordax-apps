    FERRAMENTAS DO GPT
    OrdaX MCP · conexão de teste
    O Forjador usa Groq e acrescenta @ordax-mcp automaticamente às tarefas enviadas ao GPT Web. O plugin precisa estar disponível na conta; a seleção Owner do dispositivo continua obrigatória. A verificação não envia mensagens nem cria arquivos.
    Seleção do plugin não verificada.
    O marcador visual do plugin não comprova uma ação. Arquivos e comandos só contam como feitos quando houver recibo verificável. O futuro MCP Forge será uma conexão separada, usando o mesmo Forjador.
