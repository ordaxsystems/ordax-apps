# Arquivo de shells anteriores do OrdaX 3D

Este branch preserva os shells exploratórios de Biblioteca de impressão, Materiais e custos, Operações, Preparação e Qualidade/manutenção, além dos módulos de UI que foram escritos para eles.

Eles foram mantidos fora do produto ativo porque o OrdaX 3D foi consolidado como uma única capacidade vertical com um único host (`ordax-3d`). Os cinco diretórios não são apps instaláveis, não são rotas do host ativo e não devem receber dados, stores ou lógica de domínio paralelos. O source integrado e canônico do protótipo está em `prototypes/3d-printing/apps/ordax-3d` no branch de produto.

Este branch existe para preservar o material de trabalho e permitir consulta histórica. Não representa uma proposta de reativar ou distribuir os cinco shells.
